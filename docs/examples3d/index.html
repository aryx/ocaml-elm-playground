3D examples

The same source runs on two web backends: svg compiles the 3D scene to 2D SVG polygons (sorted back to front, one color per face, no textures), webgl draws it on the GPU (a z-buffer, smooth lighting, textures). See README-3d.md.

  1. Triangle3d: src webgl (the WebGL backend's first test)
  2. Cube3d: src svg webgl
  3. Cubes3d: src svg webgl
  4. Spheres3d: src svg webgl
  5. TexturedCube3d: src svg webgl
  6. InteractiveCube3d: src svg webgl
  7. PaintersAlgorithmFail3d: src svg webgl
  8. FloatingCity3d: src svg webgl
  9. Corridor3d: src svg webgl
