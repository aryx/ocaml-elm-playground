The library, area by area

Everything written from scratch, one idea per module, each interface explaining its idea: the playground, graphics, physics, audio, AI, GUI, networking, cryptography and compression, the terminal, application engines, game kits, languages.

Play online

tinybox: every game and app in one menu, as the native tinybox (arrows, Enter to play, Back to return).

The code map: this whole repository as a map, zoomed into down to the code (h for its keys; its manual).

Games: every game, by genre, in your browser.

Apps: the applications, by category.

By size: the games and apps together, the smallest first (lines of code).

Examples: the demos of one feature each, 2D and 3D.
