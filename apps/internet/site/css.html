Style sheets

The looks of this page are not in its HTML but in rules at its top, in a <STYLE> element: the colours, the sizes, the margins, even what is not shown. Press c to see the page without them, as Netscape 1.1 would: the same tree, the browser's looks.

The cascade

Each paragraph below is a <P>; four rules could give it its colour, and the one with the highest specificity wins: 

p        { ... }                (0, 0, 1)
.note    { color: green }       (0, 1, 0)
p.note   { color: #8B0000 }     (0, 1, 1)
#top     { color: blue }        (1, 0, 0)

This one has class=note: p.note beats .note and p, dark red and in italics.

This one has id=top too: #top beats them all, blue (and still in italics: no rule of higher specificity says otherwise).

And this one says its own colour, style="color: ...": that beats every rule.

What no rule says is inherited: the items of this list are grey, because of ul li, and their emphasis is bold because of em:

  • a selector names elements, classes and ids;
  • a descendant selector, two of them, an element inside another;
  • and a class alone matches any element.

This paragraph has display: none: no browser that reads the style sheet shows it.
